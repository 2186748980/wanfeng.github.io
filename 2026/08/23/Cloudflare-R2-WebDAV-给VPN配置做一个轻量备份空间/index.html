Cloudflare R2 WebDAV：给 VPN 配置做一个轻量备份空间

日期：2026-08-23　作者：鱼

用 Cloudflare R2 存储文件，用 Worker 提供 HTTPS + Basic Auth 的 WebDAV 接口，不需要 VPS。

为什么做这个项目

在 Android 上使用 Mihomo、Clash、sing-box 等软件时，配置文件经常需要备份。如果只是为了保存几个配置文件，专门准备一台 VPS 显得有些重。因此做了一个面向单用户场景的轻量 WebDAV 服务。

整体结构

VPN / OpenList / WebDAV 客户端
              ↓ HTTPS
      Cloudflare Worker
              ↓ R2 Binding
        Cloudflare R2 Bucket

支持的 WebDAV 操作

实现了 OPTIONS、PROPFIND、GET、HEAD、PUT、DELETE、MKCOL、COPY、MOVE 等常见方法。

目录使用零字节对象作为目录标记，同时也能识别已有对象前缀形成的隐式目录。PROPFIND 返回标准的 207 Multi-Status XML，并限制在 Depth 0/1，避免轻量备份场景出现过大的递归目录请求。

安全设计

  • 所有 WebDAV 方法都需要 Basic Auth。
  • 通过 Worker 的 HTTPS 地址访问。
  • 用户名和密码使用 Cloudflare Worker Secrets 保存。
  • 仓库不保存实际账号、密码、API Token、Bucket 或域名。
  • R2 Bucket 通过 Worker Binding 访问，不需要单独创建 R2 S3 API Token。

部署

npm install
npx wrangler login
npx wrangler r2 bucket create your-webdav-bucket
npx wrangler secret put WEBDAV_USERNAME
npx wrangler secret put WEBDAV_PASSWORD
npx wrangler deploy

部署成功后可以获得一个 workers.dev HTTPS 地址，也可以进一步绑定自己的 Cloudflare 域名。

OpenList 也可以直接挂载

在 OpenList 中新增 WebDAV 存储，填写 Worker 的根地址、用户名和密码即可。根路径可以使用 /，也可以限制为 /backups。

适合什么场景

这个项目定位非常明确：它不是为了做大型网盘，而是给配置文件、脚本、小型备份提供一个轻量的 WebDAV 入口。对于 VPN 配置、OpenList 配置以及其他需要跨设备同步的小文件，这种架构已经足够实用。

本地测试

npm run check
npm test

项目测试使用内存模拟 R2，不需要 Cloudflare 凭据即可验证核心 WebDAV 流程。
